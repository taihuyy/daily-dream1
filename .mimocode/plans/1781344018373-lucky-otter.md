- **项目位置**: 新建独立目录 `D:\AI\mi\mini-dream`
- **用户体系**: 微信登录 + 云数据库

## 云数据库集合

### `users`
| 字段 | 类型 | 说明 |
|------|------|------|
| openid | string (unique) | 微信 openid |
| nickName | string | 昵称 |
| avatarUrl | string | 头像 |
| totalDreams | number | 梦境总数 |
| createdAt | serverDate | 创建时间 |

### `dreams`
| 字段 | 类型 | 说明 |
|------|------|------|
| userId | string (indexed) | 所属用户 openid |
| title | string | AI 生成标题 |
| rawText | string | 用户原始输入 |
| fullText | string | AI 整理后全文 |
| tags | array\<string\> | 标签 |
| feeling | string | 感受 |
| imageUrl | string | AI 生成图片云存储路径 |
| isPublished | boolean | 是否发布到广场 |
| isAnonymous | boolean | 匿名发布 |
| likes / commentsCount / shares | number | 社交计数 |
| createdAt | serverDate | 创建时间 |

### `likes`
| 字段 | 类型 | 说明 |
|------|------|------|
| userId | string | 点赞用户 |
| dreamId | string (indexed) | 梦境 ID |
| createdAt | serverDate | 时间 |

### `comments`
| 字段 | 类型 | 说明 |
|------|------|------|
| dreamId | string (indexed) | 梦境 ID |
| userId | string | 评论用户 openid |
| userNickName | string | 评论者昵称（冗余，查询免联表） |
| userAvatarUrl | string | 评论者头像 |
| content | string | 评论内容 |
| createdAt | serverDate | 时间 |

### `notifications`（可选，Phase 5+）
| 字段 | 类型 | 说明 |
|------|------|------|

## 云函数设计

### 1. `login` — 微信登录
- 获取 `OPENID`，upsert `users` 集合，返回用户信息

### 2. `ai-chat` — 通用 LLM 对话（核心）
```
PROVIDERS = {
  moonshot: { baseUrl, model, apiKey },
  mimo: { baseUrl, model, apiKey },
  deepseek: { ... }  // 随时添加
}
```
- 接收: `{ provider, messages, systemPrompt, temperature }`
- 内部: `callOpenAICompatible()` 发 HTTP 请求
- 返回: `{ content, usage, model }`
- **切换模型**: 只改云函数 PROVIDERS 配置，客户端零改动

### 3. `generate-image` — 图像生成
- 调用通义万相 DashScope API
- 结果上传云存储，返回 `fileID`

### 4. `dream-crud` — 梦境 CRUD
- 创建梦境、更新梦境、获取用户梦境列表

### 5. `dream-action` — 社交操作
- 点赞/取消点赞（写入 `likes` 集合 + 更新 `dreams.likes` 计数）
- 发表评论（写入 `comments` 集合 + 更新 `dreams.commentsCount` + 返回新评论）
- 获取评论列表（按时间倒序，分页 20 条）
- 评论点赞

## 验证方案

1. **登录流程**: 启动小程序 → 自动获取 openid → 云数据库 users 集合有记录
2. **记录流程**: 输入梦境文字 → 选择标签 → AI 对话追问 3-5 轮 → 生成结果（标题+全文+标签）
3. **图像生成**: 点击生成 → 云函数调用通义万相 → 图片显示在结果页
4. **发布流程**: 设置匿名/公开 → 发布 → 广场出现该梦境
5. **广场用户区分**: 匿名用户显示 "匿名做梦者" + 默认头像；非匿名显示真实头像昵称
6. **评论功能**: 点击评论输入框 → 输入内容 → 发送 → 评论出现在列表 → commentsCount +1
7. **点赞去重**: 同一用户重复点赞 → 写入失败（唯一索引）→ 前端取消心形
8. **个人中心**: 显示用户所有梦境，统计正确
9. **模型切换**: 修改云函数 PROVIDERS 配置 → 客户端无感切换
