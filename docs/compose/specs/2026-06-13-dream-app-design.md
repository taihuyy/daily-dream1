# 梦境 App 设计文档

## [S1] 问题描述

用户需要一个自用的安卓 App，用于记录梦境、通过 AI 总结梦境，并根据总结生成图像和视频。App 需要接入两个模型：
- 小米 MiMo API：用于总结梦境和多轮对话调整
- 通义万相 API：用于生成图像和视频

## [S2] 解决方案概述

扩展现有的 Flutter 应用“每日梦境”，添加通义万相 API 客户端，修改设置以支持 MiMo API，添加图像/视频生成页面。

## [S3] 架构

### 技术栈
- UI 框架：Flutter
- 状态管理：Provider
- 本地存储：Hive
- AI 后端：MiMo API（OpenAI 兼容）
- 图像/视频生成：通义万相 API

### 组件
1. **SettingsService**：修改以支持 MiMo API 配置（基础 URL、模型名称）
2. **AiService**：修改以支持 MiMo API（更改基础 URL 和模型）
3. **TongyiWanxiangService**：新增，用于调用通义万相 API 生成图像和视频
4. **ImageVideoProvider**：新增，管理图像/视频生成状态
5. **ImageVideoPage**：新增，图像/视频生成页面

## [S4] 数据流

1. **梦境输入**：用户输入梦境（文本或语音）→ AiService（MiMo API）→ 初步总结梦境（标题、摘要、细节）
2. **多轮对话调整**：用户与 AI 多轮对话，调整梦境描述，AI 引导用户细化细节
3. **生成请求**：用户确认梦境内容后，请求生成图像/视频
4. **图像/视频生成**：TongyiWanxiangService（通义万相 API）生成图像和视频
5. **存储**：存储梦境和生成的图像/视频到 Hive

## [S5] 错误处理

1. **API 调用失败**：显示友好错误提示，允许重试
2. **生成超时**：显示进度条和重试选项
3. **网络断开**：本地数据正常显示，生成操作暂停
4. **API 隔离**：MiMo API 和通义万相 API 分别处理错误，互不影响

## [S6] 测试策略

1. **单元测试**：AiService、TongyiWanxiangService 的 API 调用逻辑
2. **Widget 测试**：图像/视频生成页面的 UI 交互
3. **集成测试**：完整的梦境记录到生成流程
4. **手动测试**：在真机上测试语音输入和 API 调用
